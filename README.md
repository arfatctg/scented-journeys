# Scented Journeys

Create a modern, elegant e-commerce website for "DecantologyBD" — an online store 

that sells perfume decants (small authentic samples of designer/niche fragrances 

in various ml sizes like 3ml, 5ml, 10ml).

BRAND & DESIGN

- Name: DecantologyBD

- Aesthetic: luxurious, minimal, sophisticated — think dark charcoal/black, gold, 

  and cream/ivory color palette with elegant serif fonts for headings and clean 

  sans-serif for body text

- Feel: premium fragrance boutique, not a generic store

PAGES

1. Home page:

   - Hero section with brand tagline and a featured perfume image

   - "Shop by Category" section (Men, Women, Unisex, Niche, Arabic/Oud)

   - Best sellers / New arrivals carousel

   - Trust badges (100% Authentic, Fast Delivery, Secure Payment)

   - Newsletter signup

2. Shop / All Products page:

   - Grid of product cards (image, name, brand, price per ml size)

   - Filters: Brand, Gender, Price range, Size (3ml/5ml/10ml/30ml)

   - Sort by: Price, Newest, Popularity

   - Search bar

3. Product Detail page:

   - Multiple images, fragrance notes (top/heart/base notes shown visually)

   - Size selector with dynamic price update

   - Add to cart button

   - Description, longevity/sillage info

   - Related products

4. Cart & Checkout page:

   - Cart summary, quantity editing

   - Checkout form (name, address, phone, payment method — cash on delivery + 

     bKash/Nagad options since this targets Bangladesh)

5. About page:

   - Brand story, why decants, authenticity promise

6. Contact page:

   - Contact form, WhatsApp/Facebook link, location info

FUNCTIONALITY

- Fully responsive (mobile-first, since most BD customers will browse on phone)

- Shopping cart with local state management

- Product filtering and search functionality

- Smooth animations/transitions on scroll and hover

- WhatsApp floating button for quick customer support

Use placeholder product data for at least 12 perfumes with realistic names, 

brands, notes, and prices in BDT (Bangladeshi Taka).
